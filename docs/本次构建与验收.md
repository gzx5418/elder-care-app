## 与原文的实现差异

- 原文的历史测试人数、103 项真机测试、五品牌通知验证与包体大小未复用为本次结论。
- 页面使用单页路由承载八个屏幕，共用 SVG 图标系统；实现所需图标，不重复创建 80 个未使用图标。
- 本地规则数据作为 JS 单一数据源，在构建时导出三个带版本与来源信息的 JSON，避免重复维护。
- 原生桥接是可检查的 Java Capacitor 插件；TTS 与语音通过 intent queries 声明服务可见性，无需列举所有厂商包名。
- 家属通知使用系统短信/分享确认，不静默发送、不提供远程推送。
- 已保存 API Key 沿用文档演示模式，本次没有实现 Keystore；默认仅内存暂存。
- 日历同步通过 CalendarProvider 创建本地“银龄助手提醒”，按吃药 15 分钟、其他 30 分钟提前提示；日历事件不随本地提醒自动更新。
- Capacitor 升级至 6.2.2 修复公开漏洞；Gradle 使用支持 JDK 21 的 8.5。
