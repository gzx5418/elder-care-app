# v3.2.2 语音输入与自动朗读

修复手机没有系统语音识别服务时无法输入的问题。百炼 AI 模式采用原生麦克风录制 AAC，普通话和受支持方言由 qwen3-asr-flash 转写。录音上传前确认，最多 30 秒；取消、离开页面会删除录音而不上传。允许麦克风权限后，点“点一下说话”，说完点“说完了”，核对文字再提问。

回答默认自动朗读，内容包含本地建议与 AI 补充。提供再次朗读、停止朗读；设置中可关闭自动朗读。优先用手机中文引擎，无引擎时调用百炼 qwen3-tts-flash（Cherry 中文声音），长回答分段播放。云语音使用脱敏回答，计入每日 30 次联网调用上限。急症只尝试本机朗读，不等待云服务，立即显示 120。

按钮缩短文案并在窄屏或特大字体时换行布局，避免文字挤成纵向长列。升级时仅替换百炼配置中旧硅基语音默认模型，保留用户运行模式及密钥停用状态。

## 验证

- 真实 ASR：HTTP 200，0.61 秒，准确识别“我想知道怎么给手机交话费。”。
- 真实 TTS：HTTP 200，1.39 秒，中文音频下载 HTTP 200，253484 字节。
- 53 项引擎测试、19 项界面回归、8 项语音交互测试通过，包含自动朗读内容、云语音兜底、停止与重播、取消不上传、急症零云请求、窄屏布局和旧配置迁移。
- Android APK 编译和 lint 完成。尚未连接用户手机；麦克风硬件、扬声器播放和权限需安装后实测。

运行预览后：`node scripts/speech-ui-check.mjs`。证据：`test-results/speech-live.json` 与 `test-results/speech-ui.json`。测试使用合成语音，没有上传用户录音。

官方协议：[百炼 Qwen ASR](https://help.aliyun.com/zh/model-studio/recording-file-recognition-qwen)、[Qwen TTS API](https://help.aliyun.com/zh/model-studio/qwen-tts-api)。

## v3.2.3 更新

依用户最新要求取消录音前提示，点击麦克风即授权本次录音上传；安静约两秒自动识别，不再需要点击说完。8 秒未听到讲话则取消且不上传；仍可手动取消，最长 30 秒。语音提醒会解析完整指令填入表单，确认后才保存。联网模式没有本地匹配时只显示联网回答及通用错误提示，不显示离线未找到文案。
