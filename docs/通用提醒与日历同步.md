# v3.2.4 通用提醒与自动日历同步

## 使用

提醒页直接点击“语音设置提醒”，例如“提醒我明天下午三点去超市买菜”。说完停顿约两秒自动识别。日期、时间、事项完整时立即保存，并同步手机日历，无需保存确认或单独点击同步。识别缺少时间或日期不明确时打开表单补充，避免按错误时间创建事件。

手动添加也使用通用事项，默认一次性，提供吃药、喝水、复诊、缴费、生日、其他类别。保存和修改自动同步；编辑复用原事件，删除同步删除关联事件。日历在指定时刻提醒，应用通知独立安排。

首次必须允许 Android 的麦克风、日历与通知权限。日历权限拒绝或服务不可用时，本地提醒仍保存，卡片显示“日历未同步”。恢复权限并重新返回 App 后自动重试。已完成或未完成状态与系统通知策略沿用原有实现。浏览器预览不支持手机日历并明确提示。

## 验证

70 项单元检查、19 项界面回归、12 项语音界面检查及 4 项原生日历桥接模拟检查。模拟检查覆盖保存自动调用、编辑复用事件、权限失败保留本地提醒、删除关联事件。Android 编译、lint 和 APK 签名校验通过。

未连接安卓真机，CalendarProvider 实际写入、国产日历显示与权限流程仍须安装验收。日历存储使用应用本地账户，按事件 ID 与提醒标记查找更新；已删除事件不用于复用。

报告：`test-results/calendar-ui.json`、`test-results/speech-ui.json`。运行预览后执行 `node scripts/calendar-ui-check.mjs` 和 `node scripts/speech-ui-check.mjs`。
