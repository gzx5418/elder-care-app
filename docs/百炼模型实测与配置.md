# 百炼模型实测与默认配置

日期：2026-10-09。根据用户要求，默认切换为联网 AI，默认服务商为阿里云百炼，私用 APK 预置用户提供的 API Key。此文和测试报告不包含密钥。

## 默认配置

- Endpoint：`https://dashscope.aliyuncs.com/compatible-mode/v1`。
- 文本：`qwen-flash`，`enable_thinking=false`，强调短句、最多五步，减少等待。
- 图片：`qwen3-vl-flash`，用于截图文字提取，再由本地规则判断风险。
- 联网失败继续显示本地指引；反诈等级保持本地判断；急症不请求 AI。
- v3.2.2 默认直接录音并调用百炼 qwen3-asr-flash，回答自动朗读，缺少中文引擎时使用 qwen3-tts-flash。识别与合成真实接口已验证，见《语音输入与自动朗读》。
- 设置页可测试已保存的 AI 配置，也可停用预置密钥。停用后重开不自动恢复，手动输入自己的密钥仍可使用。

## 真实接口验证

四个文本候选的单次连通性探测全部 HTTP 200。随后每个候选分别调用生活、已转账诈骗、健康科普三个场景，并测试两个视觉候选，总共 18 次初始/比较请求。修订面向老人的提示词后，对最终文本模型再验证三个场景；App 内另做两次真实请求（连接测试和生活问答）。以上共 23 次真实请求，样本均为人工构造内容，未上传用户私有提醒、健康或家属数据。

| 文本模型 | 三场景成功数 | 响应中位数 | 选择依据 |
| --- | --- | --- | --- |
| qwen-flash | 3/3 | 1.00 秒 | 这次样本中最快；中文步骤简洁；选为默认 |
| qwen-plus | 3/3 | 5.43 秒 | 内容可用，本次响应更慢 |
| qwen3.8-flash | 3/3 | 3.68 秒 | 内容可用，本次回答更长 |
| qwen3.7-plus | 3/3 | 3.52 秒 | 内容可用，但出现过多步骤和内部术语 |

最终提示词增加“普通生活问题不套用反诈报警建议”“最多五步”和“保留证据”。选定 qwen-flash 重测三个场景均成功，响应中位数 0.97 秒。生活指引核对号码和金额、反诈保留证据并联系银行与110、健康不自行停药和咨询医生均有覆盖。

视觉测试用本机生成的中文样例图：`qwen3-vl-flash` 和 `qwen-vl-plus` 均正确提取关键文字，耗时分别 0.54 秒和 0.44 秒。单张图片不能证明通用 OCR 准确率；选择 qwen3-vl-flash 作为当前视觉预设，可在设置中换用其他百炼视觉模型。

选择基于这个 App 的短问答需求、当前账号可用性和少量样例，不是全模型评测。耗时含本机网络与排队，不能保证其他时间或手机也有同样速度。

## 证据与检查

- `test-results/bailian-probe.json`：四个模型连通性、输出与 token 用量。
- `test-results/bailian-comparison.json`：三场景比较与两个图像模型，保留原始输出。早期正则对“切勿删除”“严禁停药”存在误判，人工复核后确认这些回答没有建议删除证据或自行停药，不将正则分数视为专业安全评测。
- `test-results/bailian-selected.json`：最终提示词下的三个选定模型样例。
- `test-results/bailian-live-ui.json`：真实浏览器集成验证，包含默认配置、空密钥显示框、连接测试、生活问答、急症零 AI 请求、停用密钥重开后不恢复，共六项。
- 原有 53 项引擎测试与 19 项界面回归通过。Android 通知等真机能力仍待手机验收。

## 私用构建与分享

密钥保存在本机忽略目录 `.local/bailian.json`，构建时注入到私用 APK，设置页不会显示原文。APK 中预置的密钥仍可通过解包提取，本包不得公开分发。清除功能只停用应用内使用，无法从已分发安装包中抹除密钥。

源码压缩包排除 `.local/` 和包含密钥的生成 JS。源码本身不含真实密钥，重新构建时请自行设置本机配置或环境变量 `BAILIAN_API_KEY`。如需不带密钥的版本：

```powershell
$env:BUILD_WITHOUT_PRIVATE_KEY='1'
npm.cmd run sync
# 然后构建 APK；安装后由使用者自行填写密钥
Remove-Item Env:\BUILD_WITHOUT_PRIVATE_KEY
```

百炼服务为按量付费，本次测试可能计入账号账单；仍保留应用每日 30 次联网请求上限。
