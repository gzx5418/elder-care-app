# 银龄助手 Android App

当前版本：v3.2.4 百炼私用版。按用户要求，默认联网 AI、预置百炼配置与私用密钥。文本模型 qwen-flash，视觉模型 qwen3-vl-flash，真实接口验证已通过。详见 [百炼模型实测与配置](docs/百炼模型实测与配置.md)。

此 APK 含预置密钥，勿公开分发；源码包不包含真实密钥。

按目录中的《银龄助手项目综合文档.docx》重新实现的 v3.2 应用。原目录仅有文档，没有历史源码或 APK。本项目的代码、截图与测试结果均来自本次构建，文档中原有的 103 项真机测试、五品牌验证及 4.98 MB 包体数据不作为本项目的验证结论。

## 安装使用

安装包在 `release/银龄助手-v3.2.4-百炼私用版.apk`。通过 USB 或文件传输复制到安卓手机，打开 APK，按系统提示允许此来源安装。支持 Android 6.0 / API 23 及以上，需要较新的 Android System WebView。

默认联网 AI，安装即可调用预置百炼配置，不需要注册或启动后端。网络不可用时回退本地指引，可以在设置中切回离线。首次设置提醒时允许通知权限；在提醒页开启“准时提醒”权限，并允许后台运行。系统强制停止、厂商省电限制、私人空间锁定等可能阻止通知，重要药物请同时保留其他提醒方式。

这是使用 Android 调试证书签名的测试包，可直接安装。正式公开发行需要使用自己的签名证书生成 Release APK/AAB；请保管好签名证书。

## 已实现

- 八个功能页面：首页、生活助手、反诈检测、检测结果、健康指南、通用提醒、家属联系、应用设置。
- 离线生活知识 10 类；健康知识 7 类；九类急症检测直接提示 120；健康内容附科普说明。
- 反诈规则评分、三档风险、敏感链接组合规则、已操作应急分流、110/96110 拨号与可编辑报警说明。
- 提醒新增、修改、删除、每日重复、完成记录、10 分钟稍后提醒、两次延迟警示、Android 系统通知与通知操作按钮。
- 家属电话本地保存，高危或吃药延迟时调用系统短信/分享界面，由使用者确认发送。
- 回答自动朗读（含 AI 补充），支持停止与再次播放；原生中文 TTS 优先，百炼云语音兜底。百炼直接录音识别、系统拨号与剪贴板、可选本地日历同步。
- 四家 OpenAI 兼容 AI 服务商预设、文本和视觉模型独立配置、临时密钥或本机保存、清除密钥、每日 30 次请求限制、隐私脱敏、AI 失败回退本地。
- 图片压缩至最长边 1280px，限制 10MB，确认上传后提取文字，用户复核后才执行本地反诈检测。
- 武汉话、四川话、上海话、粤语、普通话、自动识别六种语音选项。默认百炼 qwen3-asr-flash 自动识别普通话及受支持的方言；硅基流动配置仍保留。武汉话准确率需实测。
- 适老化暖色界面、大字和特大字体、大按钮、SVG 图标、响应式布局、减少动画偏好。
- 可选 FastAPI 本地调试服务，复用同一 JS 规则引擎，带鉴权、限流、CORS/Host 白名单、安全响应头。

## 明确限制

1. 文本、视觉、百炼语音识别与语音合成接口已使用用户提供的密钥完成真实调用验证；硅基流动接口未使用真实密钥验证。服务商模型名称、权限、价格和方言准确率以实际账号为准；预设模型可以修改。不保证全部方言的识别效果。
2. 未连接安卓真机，因此系统通知、中文语音引擎、语音输入、日历和国产机后台策略需要真机验收。已完成 APK 编译、静态检查与浏览器交互验证。
3. 家属模式是本机联系功能，不提供远程后台消息推送或静默发短信。两次吃药推迟后可打开系统短信草稿；最后发送由使用者确认。
4. 离线图片 OCR 未实现，与文档 v3.2 的限制一致。
5. 本机保存密钥未采用 Keystore，仅供演示。用户手动填写的密钥默认仅内存暂存；此私用版的预置密钥随 APK 提供，重开无需填写，可以在设置页停用。
6. 日历事件与应用提醒独立。删除或修改 App 提醒不会同步更改已导出的日历事件；请在系统日历中处理，避免重复同步。
7. 反诈为本地启发式判断，低风险不等于安全；健康知识没有经过临床验证，不作为诊断或用药建议。
8. 采用单页路由呈现八个页面，统一入口 `src/index.html`；并非文档历史工程的八个独立 HTML 文件。统一数据源为 `src/data.js`，构建时导出带版本信息的三个 JSON。

## 开发和构建

环境：Node.js 20+、JDK 17 或 21、Android SDK Platform 34、Build Tools 34.0.0。工程使用 Capacitor 6.2.2、Gradle 8.5 和 AGP 8.2.1，以适配本机 JDK 21。中文路径已启用 `android.overridePathCheck`。

```powershell
cd elder-care-app
npm.cmd ci
npm.cmd run build
npm.cmd run preview
# 浏览器打开 http://127.0.0.1:8080

# 一键构建（路径按自己的环境修改）
.\scripts\build-apk.ps1 -SdkPath 'D:\Android\Sdk' -JavaPath 'D:\Java\jdk-21.0.12'

# 或通过 Android Studio
npm.cmd run android
```

每次修改 `src/` 后执行 `npm.cmd run sync`，否则手机安装包中的页面不会更新。启动图标生成脚本需 Pillow：`python scripts/generate-icons.py`。

构建下载使用华为 Gradle 镜像并验证 SHA256，Maven 添加阿里云镜像；也可将仓库改回官方源。Capacitor 6 CLI 依赖旧 tar，项目固定 `tar@7.5.22` 并在 `postinstall` 应用已知 CommonJS 调用兼容补丁。运行 `npm ci` 会自动执行此步骤，不要加 `--ignore-scripts`。

## 可选后端

```powershell
python -m pip install -r backend/requirements.txt
$env:DEBUG_API_KEY='请设置自己的调试密钥'
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

在应用设置中选择“服务器调试版”，填写相同的调试密钥。浏览器使用 `127.0.0.1:8000`；模拟器使用 `10.0.2.2:8000`；USB 真机可先执行 `adb reverse tcp:8000 tcp:8000`，再使用 `127.0.0.1:8000`。HTTP 调试只在 Debug 包对这些本机地址开放；Release 使用 HTTPS。

`ENV=prod` 时关闭 API 文档。调试服务不部署公网，无密钥时业务接口拒绝请求。提醒 CRUD 是独立的临时内存调试数据，不同步手机本地提醒。Node.js 必须在 PATH 中，或设置 `NODE_BINARY`。

## v3.2.4 交互调整

联网未匹配时直接显示 AI 回答，不提示离线未找到。语音点击即录制，无上传确认弹窗；安静约 2 秒自动识别，全程没有说话 8 秒则退出并不上传。首次系统麦克风权限仍须允许。说“提醒我明天早上八点吃药”，会填写一次性提醒的日期、时间、事项，点“确认设置提醒”后保存。缺失时间请补充，不使用默认时间替代。支持今天、明天、后天、具体日期、星期、每天与若干分钟/小时后。

验证：70 项单元测试、19 项界面回归及语音集成检查。未连接真机，手机环境噪声与权限仍需实测。

## v3.2.4 通用提醒与日历自动同步

提醒页面直接显示“语音设置提醒”。例如“提醒我明天下午三点去超市买菜”，说完停顿后自动识别、保存一次性提醒并同步手机日历，不再要求确认保存或另点同步。语音缺少时间等必要信息时打开表单补充；手动添加和编辑也自动同步。默认手动提醒为一次性、其他类型，吃药仍是可选类别。

首次需允许系统麦克风、日历及通知权限。没有权限时保留本地提醒并显示日历未同步，恢复权限并返回应用后自动重试。修改更新同一个日历事件，删除同时清理关联事件。日历事件按指定时刻提醒。浏览器预览不能访问手机日历，明确标注该限制。

验证包括日历桥接模拟：自动保存、编辑复用事件、拒绝权限时保留本地提醒、关联删除；实际 Android CalendarProvider 和手机通知仍需真机验收。
